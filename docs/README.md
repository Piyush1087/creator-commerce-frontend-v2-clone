# Frontend Docs

Use this folder for frontend-specific operational notes.

Start with the root `RUNBOOK.md` before using these docs. The runbook is the
main tracker for current status, temporary work, next tasks, and doc references.

Suggested structure:

- `deployment` for SST, AWS profile, domain, and certificate notes.
- `local-development` for local env, backend connection, and run commands.
- `design-system` for tokens, shared components, and UI decisions once added.
- `temporary-playgrounds` for mock-only pages used to visually test UI systems.
